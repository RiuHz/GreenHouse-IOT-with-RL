# GreenHouse IoT with RL

An intelligent, automated greenhouse ecosystem that combines IoT telemetry with Reinforcement Learning (RL) to create optimal growth environments.

## 🚀 Key Features

* **IoT Telemetry:** Real-time data collection from greenhouse sensors (temperature, humidity, soil moisture, light).
* **RL-Driven AI:** A remote Reinforcement Learning agent that learns optimal climate control strategies (e.g., automated watering, ventilation, heating) to maximize crop yield and efficiency.
* **Dual Control Modes:** Seamless switching between autonomous AI management and manual user control.
* **Remote Monitoring:** Dashboard capabilities to track live sensor data and agent performance metrics from anywhere.
